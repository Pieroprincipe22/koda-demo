# Koda — versión de prueba

Koda es un asistente de voz en español para Windows, hecho por Koda Estudio.

Esta es una **versión temprana para probadores invitados**. Aquí solo está el
instalador; no incluye código ni claves.

## Cómo probarla

Las instrucciones están en **https://www.kodaestudio.com/demo**

Necesitas una clave personal, que se envía por privado a cada invitado.
Sin esa clave, Koda no funciona.

## Avisos

- Koda es una inteligencia artificial: no hablas con una persona y puede equivocarse.
- Es una versión temprana y puede fallar.
- Tu opinión se envía desde la misma página de instrucciones.
